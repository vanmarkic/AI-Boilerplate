PM Questions (Domain Vocabulary)

Blue Card Scoring
Turn-dependent blue card scoring
— Currently each blue card option (SWBxx) has a fixed score. The new model says the same blue card can score differently per inject context (e.g., SWB01 "Continue Mission" scores +0 in Turn 1 but might score -1 in Turn 8). Is this turn related or inject related ?

Lo / Mid / Hi tier boundaries — After the final turn, players see a tier (Lo / Mid / Hi) instead of a number. Who defines the cut-offs? Per-scenario in the scenario pack? Fixed percentages of max achievable score?

Stress sources — blue card vs. inject/turn — The scenario pack shows stress deltas per blue card choice (e.g., Turn 4 best path = Stress +1, Turn 6 = Stress +2). Are these the only stress inputs, or do some injects carry an independent stress modifier on top of the blue card consequence? Is there a per-turn base stress increment?

Stress accumulation & cap — The briefing shows stress 0–10. Is 10 the hard cap? What happens at stress 10 — decision time floors at 3:00, or are there additional gameplay effects (UI changes, forced cards, restricted options)?

Initial system state — The scenario pack defines initial conditions per scenario (e.g., Turn 0: NAV RADAR ON/Green, AAW RADAR OFF/Green, etc.). So initial ON/OFF + operational state is scenario-defined in the scenario pack — confirmed?

System state change triggers — The scenario pack shows systems changing state via inject consequences and blue card effects (e.g., "Reboot triggers silent privilege escalation → AAW RADAR Yellow"). Are all state transitions authored in the scenario pack (Facilitator-driven), or can some be auto-triggered by the engine based on rules?

Blue card targeting a system — "A blue card that can repair multiple systems can only be played on one." Example: SWB14 "Reboot Affected System" or SWB10 "Isolate System" — does the CO choose which system to target via a system picker in the UI? Is this a new interaction on top of the current "select up to 2 blue cards" flow?

System catalog — The scenario pack lists 6 systems (NAV RADAR, IBMS/INS, NAV SENSORS, ASUW TRACKING RADAR, COMMS, AAW RADAR) + 5 weapons (CIWS FWD/AFT, Missile Launcher, Gun, Decoys). Is this catalog fixed per domain config, or variable per scenario?

Turn History Drawer
History drawer contents — Should the drawer show the full board state evolution: injects received, blue cards played, system state changes, stress changes, and Facilitator notes per turn? Or just injects + blue card decisions (the event and decision log)?

Role-filtered or global view? — The briefing shows role-targeted injects (e.g., NAV sees navigation data, CyOp sees cyber alerts). In the history drawer, does each player see only what their role received, or the full picture across all roles?

Turn 0 — Pre-Sail Briefing
Turn 0 scope — The scenario pack explicitly has "Turn 0 – Pre-Sail Briefing" with role-targeted injects (OPS, NAV, EO, CyOp) and an initial board state. The engine already has a BRIEFING phase. Is Turn 0 simply mapping this existing phase to display the Turn 0 injects as briefing cards, with the Facilitator prompt "prepare a mission briefing for your CO"?

Turn 0 decisions — Turn 0 in the scenario pack has no blue cards. Is Turn 0 always read-only (no decisions), or could future scenarios include blue card choices during the briefing?
