## What This Is

This is a monorepo containing two applications:

1. **Main App** (`apps/main/`) — A full-stack web application template (Angular + FastAPI + PostgreSQL + Keycloak). Serves as a boilerplate for new projects. See [`apps/main/SPECS.md`](apps/main/SPECS.md).
2. **TFC — Training Flow Control** (`apps/tfc/`) — A domain-agnostic exercise simulation platform. See [`apps/tfc/SPECS.md`](apps/tfc/SPECS.md).
