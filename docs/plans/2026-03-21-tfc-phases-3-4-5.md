# TFC Phases 3–5: System Effects → Codegen → Frontend

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete the system effects pipeline end-to-end: backend engine (done) → codegen → frontend state → frontend UI. Add Turn 0 labeling, Logs drawer for in-game audit trail, and seed data migration.

**Architecture:** Backend engine emits `SystemStateChange` and `ScoreChange` (with stress) via WebSocket. Codegen regenerates TS types from Python TypedDicts. Frontend store gains a `systems` signal, WS handler routes `system_state_change`, and UI renders a system status board + stress bar. Audit trail is wired to engine state changes and exposed via a "Logs" drawer during gameplay. Briefing phase displays as "Turn 0".

**Tech Stack:** Python TypedDicts → codegen → Angular 21 signals + ngrx signalStore + native CSS

```typescript
@Component({
  selector: 'tfc-logs-drawer',
  standalone: true,
  imports: [DrawerPanelComponent, DatePipe],
  template: `
    <ui-drawer-panel side="right" [open]="open()" (closed)="open.set(false)">
      <h2 drawerTitle>Logs</h2>
      <div class="logs-list">
        @for (entry of sortedLogs(); track entry.id) {
          <div class="log-entry" data-testid="log-entry" [attr.data-type]="entry.entry_type">
            <span class="log-time">{{ formatPT(entry.play_time_ms) }}</span>
            <span class="log-action">{{ entry.action }}</span>
            @if (entry.target_id) {
              <span class="log-target">{{ entry.target_id }}</span>
            }
          </div>
        }
        @empty {
          <p class="logs-empty">No events yet.</p>
        }
      </div>
    </ui-drawer-panel>
  `,
})
export class LogsDrawerComponent {
  readonly open = model(false);
  readonly logs = input<AuditEntry[]>([]);

  protected sortedLogs = computed(() =>
    [...this.logs()].sort((a, b) => a.play_time_ms - b.play_time_ms)
  );

  protected formatPT(ms: number): string {
    const s = Math.floor(ms / 1000);
    const m = Math.floor(s / 60);
    return `${m}:${String(s % 60).padStart(2, '0')}`;
  }
}
```

- CSS: use `components-logs.css` — compact list, monospace timestamps, type-colored left border
- Entry type colors: phase = neutral, event = blue, decision = yellow, system = green, issue = red
